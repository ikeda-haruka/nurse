# 産婦人科クリニック 看護師採用ランディングページ（LP）

医療法人社団 桜愛会 **「さくらレディース＆マタニティクリニック」** の看護師・助産師採用を目的とした、スマートフォン最適化済みの高品質ランディングページです。

---

## 🌸 LPのコンセプト＆目的

女性の健康を支える産婦人科クリニックの魅力、スタッフが助け合う温かな職場環境を伝え、求職者（20〜40代看護師・助産師）に**「ここで安心して働いてみたい」**と感じていただくことを目指しています。

### 主な特徴
- **優しく温かみのあるデザイン**: 白、ベージュ、桜色（淡いピンク）を基調とした、清潔感と医療機関としての信頼感を両立した配色
- **スマートフォンファースト**: スマホでの閲覧・操作性を最重視したレスポンシブ設計（追従フローティングCTAバー完備）
- **求職者の不安を解消**: 未経験・ブランク歓迎の教育制度、残業月4.2h・有休消化96%などのリアルな数字、先輩インタビューを掲載
- **応募ハードルを下げる工夫**: 「履歴書不要・私服OK」の30分職場見学会、LINE公式アカウント相談、WEBエントリーフォーム

## 🚀 プレビュー・閲覧方法

### 方法1: ブラウザで直接開く（一番簡単）
`C:\gitHub\nurse\index.html` をダブルクリックするか、Google ChromeやMicrosoft Edge等のブラウザにドラッグ＆ドロップして開くだけで、すべてのデザインと機能が動作します。

### 方法2: ローカル開発サーバーを起動する（Node.js）
ターミナルまたはPowerShellで以下を実行します：

```bash
cd C:\gitHub\nurse
npm start
```

## 🌐 GitHub Pages 公開手順

### 公開後のURL
👉 **https://ikeda-haruka.github.io/nurse/**

### 初回公開の手順
1. **GitHubでリポジトリを作成**  
   ブラウザで [https://github.com/new](https://github.com/new) にアクセスし、以下を設定して作成します：
   - Repository name: **`nurse`**
   - **Public**（公開）を選択
   - ※「Add a README file」等のチェックは外した空の状態で「Create repository」をクリック
2. **コードをプッシュ**  
   ターミナルまたはPowerShellで以下を実行します：
   ```bash
   cd C:\gitHub\nurse
   git push -u origin main
   ```
3. **GitHub Pagesを有効化**  
   作成したリポジトリの **Settings** > **Pages** に移動し、**Build and deployment** の **Source** を **GitHub Actions** に設定します。（自動作成されたワークフロー `.github/workflows/deploy.yml` により数分で自動公開されます）
   *(※「Deploy from a branch」で Branch: `main` / `/(root)` を選んでも同様に公開可能です)*

## 🎨 デザインのカスタマイズについて

- **クリニック名の変更**: `index.html` 内のテキスト（`さくらレディース＆マタニティクリニック`）を置換するだけで変更可能です。
- **配色の調整**: `assets/css/style.css` の `:root` 内のカラー変数（`--color-primary`, `--color-accent-mint` など）または `index.html` の `tailwind.config` で調整できます。
- **写真の差し替え**: 実際の院内写真やスタッフ写真を `assets/images/` に配置し、`index.html` 内の `img src` を差し替えることで、実在するクリニックの写真に簡単に切り替えられます。

### 🔄 自動同期ワークフロー（GitHub Actions）
`.github/workflows/sync-issues.yml` により、`main` ブランチへコミットがプッシュされるたびに以下の処理が自動実行されます：
1. **コミット自動追記**: プッシュされたコミット情報（ハッシュ・メッセージ・URL）がマスターIssue [#6](https://github.com/ikeda-haruka/nurse/issues/6) の「コミット変更履歴（Changelog）」に自動追記されます。
2. **Issue自動コメント**: コミットメッセージに関連するIssue番号（例: `#5`）が含まれている場合、該当Issueへ反映通知コメントが自動投稿されます。
